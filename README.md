# გიო — ხმოვანი ასისტენტი (ეტაპი 1)

## რა არის მზად ამ ეტაპზე
- დიზაინი (ორბი, ანიმაცია, ჩატის ველი) — შენი სურათის მიხედვით
- დაჭერით ლაპარაკი (press-and-hold) და ცალკე მიკროფონის ღილაკი
- ხმის ამოცნობა (Speech-to-Text) და პასუხის გახმოვანება (TTS) — ორივე ტელეფონის საკუთარი Android სისტემით, ინტერნეტის/Claude API-ს გარეშე
- მარტივი ბრძანებების ამომცნობი (`src/commands.js`) — მომავალ ეტაპებზე აქ დაემატება SMS და კალენდარი

## როგორ ავტვირთოთ GitHub-ზე (ტელეფონიდან)
1. შექმენი ახალი repository (მაგ. `gio-assistant`)
2. ატვირთე ეს ყველა ფაილი, ზუსტად იგივე სტრუქტურით:
   - `package.json`
   - `vite.config.js`
   - `capacitor.config.json`
   - `index.html`
   - `.gitignore`
   - `src/main.jsx`
   - `src/App.jsx`
   - `src/App.css`
   - `src/commands.js`
   - `.github/workflows/build.yml`
3. GitHub-ის "Add file → Create new file" გამოიყენე თითოეულისთვის, ბილიკის ჩათვლით (მაგ. აკრიფე `src/App.jsx` ფაილის სახელის ველში — თავად შექმნის საქაღალდეს)

## APK-ის აშენება
- ატვირთვის შემდეგ, "Actions" ტაბში ავტომატურად ჩაირთვება "Build APK" workflow
- დასრულების შემდეგ (10-15 წუთი), "Actions" → ბოლო run → "Artifacts" → `gio-assistant-debug-apk` — ჩამოტვირთე და დააინსტალირე ტელეფონზე

## უფლებები (permissions)
Workflow ავტომატურად umატებს ამ Android permissions-ს:
`RECORD_AUDIO`, `READ_SMS`, `SEND_SMS`, `RECEIVE_SMS`, `READ_CALENDAR`, `WRITE_CALENDAR`
პირველი გაშვებისას ტელეფონი გკითხავს დართო თუ არა თითოეული — საჭირო იქნება ხელით დათანხმება (Android-ის სტანდარტული პროცესია).

## შემდეგი ეტაპები
- ეტაპი 2: ბრძანებების უფრო ჭკვიანური პარსერი
- ეტაპი 3: SMS წაკითხვა/პასუხი (`src/commands.js`-ში `sms_stub`-ის ნაცვლად ნამდვილი ლოგიკა)
- ეტაპი 4: კალენდარზე ჩანიშვნების დამატება (`calendar_stub`-ის ნაცვლად)

## შენიშვნა ქართული TTS-ის შესახებ
ტელეფონები განსხვავდება ქართული ხმის მხარდაჭერით. თუ ხმა არ ამოვა, ტექსტი მაინც გამოჩნდება ჩატში — Android-ის Settings → Text-to-Speech-იდან საჭირო იქნება ქართული ხმის პაკეტის დამატება, თუ მოწყობილობას აქვს.
